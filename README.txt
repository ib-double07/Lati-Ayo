NINO & FOLA WEDDING INVITATION
==============================
Everything is in one file: index.html (photos are embedded inside it).

TO EDIT
Open index.html in a text editor. Near the bottom, find the block
"Edit only this block for each new client" and change: names, date
(keep the +01:00 timezone), venue, schedule, phone, story, and the
music line, e.g.  music:"song.mp3"  (put song.mp3 in the same folder).

TO PUT ONLINE (cPanel / Truehost)
1. Log in to cPanel > File Manager > public_html
2. Create a folder for the couple, e.g. nino-fola
3. Upload index.html (and song.mp3 if used) into that folder
4. The page is live at: yourdomain/nino-fola

TO TEST ON YOUR PHONE
Open index.html in Chrome, or use the hosted link after upload.

NOTE: Use only photos and music you have permission to use.
